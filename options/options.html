Deep File Scanning

By default, a file VirusTotal hasn't seen before gets a neutral score — it's only checked against a hash cache, not actually scanned. Turning this on sends the file's actual content (not just its hash) to VirusTotal when it's unrecognized and under 32MB. This is a real privacy tradeoff — off by default. Local static analysis (file-signature, entropy, macro, and script checks) always runs regardless of this setting and never leaves your device.

Email Security (Gmail — read-only)

Connects with the gmail.readonly scope only — never send, modify, or delete. One-time setup (only needed once, not per person using this build):

  1. In Google Cloud Console, create an OAuth 2.0 Client ID of type "Chrome Extension", using this extension's ID (shown on its card in chrome://extensions) as the item ID.
  2. Enable the Gmail API for that project.
  3. Paste the Client ID into manifest.json's oauth2.client_id field and reload the extension.

After that, connecting is just the button below — no ID to paste here.
